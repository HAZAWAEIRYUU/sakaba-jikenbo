# 酒場の事件簿

飲みの席で遊ぶ、正体隠しのパーティーゲーム集です。幹事が部屋を作り、参加者はQRを読むだけで、各自のスマホにその人だけの秘密の役が届きます。

| 演目 | 人数 | 時間 | 内容 |
|---|---|---|---|
| もぐり酒場 | 5〜10人 | 10分 | 客だけが知る合言葉を、紛れ込んだ取締官が探る |
| 消えたボトル | 4〜8人 | 15分 | 証言を突き合わせ、うそをついている犯人を指名する |
| 秘密結社の乾杯 | 8〜30人 | 会のあいだ | 仕草の合図で仲間を探し、相手の合図を見破る |
| 相続会議 | 6〜12人 | 15分 | 秘密の目的を胸に、遺産の行方を投票で決める |

## 動かし方

- `docs/config.js` が空のままなら「お試しモード」で動きます。同じ端末のタブ同士だけがつながります。
- Firebase Realtime Database の `firebaseConfig` を `docs/config.js` に入れると、ほかのスマホから参加できます。
- 公開は GitHub Pages（`main` ブランチの `/docs`）か Firebase Hosting（`firebase deploy`）で行います。

## ファイル

- `docs/games.js` 配役と勝敗の計算
- `docs/store.js` 部屋のデータの置き場所（Firebase か、お試しモード）
- `docs/app.js` 画面と操作
- `database.rules.json` データベースのルール（試作用。誰でも読み書きできます）
- `test/` ブラウザで4つのゲームを最後まで通すテスト
